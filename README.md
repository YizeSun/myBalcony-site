# MyBalcony Privacy & Support

Public, multilingual privacy and support pages for the MyBalcony iOS app.

## Routes

- `/de/privacy`, `/en/privacy`, `/zh/privacy`
- `/de/support`, `/en/support`, `/zh/support`
- `/privacy` and `/support` redirect to German, the app’s default language

The site has no account, form, database, analytics, advertising cookies or
tracking pixels. Support uses a standard `mailto:` link.

## Development

```bash
npm install
npm run dev
npm test
```
